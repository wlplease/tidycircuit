## Use and cleanup decisions

TidyCircuit provides file listings, duplicate comparisons, and rule-based review suggestions. A match, age, extension, cache location, or size is not proof that a file is unnecessary or safe to remove. You are responsible for reviewing paths and selections and keeping backups of files you need. When the desktop source build asks Windows to move files to the Recycle Bin, success and recovery depend on Windows, drive, permissions, and Recycle Bin settings. Check the Recycle Bin and verify important files before relying on recovery. Do not use the app as a substitute for backups.
