# Contributing

Thanks for helping TidyCircuit feel clear and safe. Open an issue before large changes so work can be coordinated. Small fixes can go straight to a pull request.

- Keep scans and analysis local. Do not add analytics, file uploads, or third-party scripts that receive file data.
- Label estimates and unsupported readings accurately.
- Cleanup changes need a preview, explicit confirmation, operation record, and recovery path.
- Do not add automatic cleanup of Downloads, personal documents, browser profiles, cloud placeholders, or system directories.
- Keep the static site usable without an account or build step.
- Document new features and limitations in the README.

For security issues, follow [SECURITY.md](SECURITY.md).
